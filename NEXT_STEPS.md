# Что делать дальше после загрузки данных

## ✅ Данные загружены!

Да, данные успешно загружены в базу данных `data/bot.db`.

## Следующие шаги

### Шаг 1: Проверить данные (опционально)

Можете проверить, что данные загружены правильно:

```bash
python get_user_id.py
```

Этот скрипт покажет всех пользователей в базе данных.

### Шаг 2: Запустить бота

Теперь нужно запустить бота:

```bash
python bot.py
```

### Шаг 3: Что произойдет при запуске

1. **Бот инициализируется** - создаст/проверит структуру базы данных
2. **Отправит уведомления при запуске** - если сегодня есть занятия для вашего класса, вы получите уведомление сразу
3. **Начнет работать** - будет проверять расписание каждые 2 часа

### Шаг 4: Протестировать

1. **Напишите боту** `/start` - зарегистрируетесь
2. **Укажите класс**: `/class 8` (замените на ваш класс)
3. **Проверьте расписание**: `/schedule` или `/today`

## Пример тестирования

Если вы загрузили:
- Ученика: `(6218121239, 8, 'Иванов Иван Иванович', ...)`
- Расписание: `('Математика', 8, 'вторник', '14:00')`

И сегодня вторник:

1. Запустите бота: `python bot.py`
2. Напишите боту `/start`
3. Напишите `/class 8`
4. Вы получите уведомление о занятиях на сегодня (если время еще не прошло)

## Важно!

- **Убедитесь, что в `.env` файле указан токен бота** (`BOT_TOKEN`)
- **Пользователь должен написать `/start` боту** перед получением уведомлений
- **Укажите класс командой `/class <номер>`** чтобы бот знал, к какому классу вы относитесь

## Проверка работы

После запуска бота вы увидите в консоли:
```
Бот успешно инициализирован
Проверка грядущих занятий при запуске...
Отправлено X уведомлений о грядущих занятиях при запуске
```

Если есть занятия на сегодня для вашего класса, вы получите сообщение в Telegram!

## Если что-то не работает

1. Проверьте логи в консоли - там будет информация об ошибках
2. Убедитесь, что токен бота указан в `.env`
3. Проверьте, что пользователь написал `/start` и указал класс
4. Убедитесь, что день недели в расписании совпадает с сегодняшним днем

## Готово!

Теперь просто запустите:
```bash
python bot.py
```

И бот начнет работать! 🚀
