## Описание

AI-репетитор - это интеллектуальный помощник, который может:
- ✅ Отвечать на школьные вопросы
- ✅ Решать математические задачи и примеры
- ✅ Объяснять учебный материал
- ✅ Адаптировать объяснения под уровень класса ученика

## Установка зависимостей

```bash
pip install -r requirements.txt
```

Это установит библиотеку `openai` для работы с OpenAI API.

## Получение API ключа OpenAI

1. Перейдите на сайт [OpenAI](https://platform.openai.com/)
2. Зарегистрируйтесь или войдите в аккаунт
3. Перейдите в раздел [API Keys](https://platform.openai.com/api-keys)
4. Нажмите "Create new secret key"
5. Скопируйте полученный ключ (он показывается только один раз!)

## Настройка в проекте

1. Откройте файл `.env` в корне проекта
2. Добавьте строку:
   ```
   AI_API_KEY=ваш_api_ключ_здесь
   ```

   Пример:
   ```
   AI_API_KEY=sk-proj-abc123def456ghi789...
   ```

3. (Опционально) Настройте модель:
   ```
   AI_MODEL=gpt-4o-mini
   ```

   Доступные модели:
   - `gpt-4o-mini` - быстрая и дешевая (рекомендуется для тестирования)
   - `gpt-4o` - более мощная, но дороже
   - `gpt-3.5-turbo` - старая версия, дешевле

## Проверка работы

1. Запустите бота:
   ```bash
   python bot.py
   ```

2. В логах должно появиться:
   ```
   AI-репетитор успешно инициализирован
   ```

3. Напишите боту любой вопрос, например:
   - "Что такое фотосинтез?"
   - "Реши пример: 25 * 4 + 10"
   - "Объясни теорему Пифагора"

## Как это работает

### Обработка вопросов

Когда ученик пишет боту вопрос:
1. Бот определяет класс ученика (если указан)
2. Вопрос отправляется в OpenAI API
3. AI генерирует ответ, адаптированный под уровень класса
4. Бот отправляет ответ ученику

### Математические задачи

Для математических задач AI:
- Показывает пошаговое решение
- Объясняет каждый шаг
- Проверяет правильность ответа

### Адаптация под класс

AI автоматически адаптирует объяснения:
- Для младших классов - простые слова и примеры
- Для старших классов - более сложные объяснения

## Стоимость использования

OpenAI API платный, но есть бесплатный кредит для новых пользователей.

**Примерные цены (на момент написания):**
- `gpt-4o-mini`: ~$0.15 за 1M токенов входных данных, ~$0.60 за 1M токенов выходных
- `gpt-4o`: ~$2.50 за 1M токенов входных, ~$10 за 1M токенов выходных

**Совет:** Для тестирования используйте `gpt-4o-mini` - она дешевле и достаточно умная.

## Безопасность

⚠️ **Важно:**
- Никогда не публикуйте API ключ в открытом доступе
- Не коммитьте файл `.env` в Git (он уже в `.gitignore`)

## Решение проблем

### Ошибка: "AI-репетитор временно недоступен"

**Причина:** API ключ не настроен или неверный

**Решение:**
1. Проверьте, что ключ добавлен в `.env`
2. Убедитесь, что ключ правильный (начинается с `sk-`)
3. Проверьте, что на счету OpenAI есть средства

### Ошибка: "Incorrect API key provided"

**Причина:** Неверный API ключ

**Решение:**
1. Проверьте ключ в `.env`
2. Убедитесь, что скопировали ключ полностью
3. Создайте новый ключ в OpenAI, если старый не работает

### Ошибка: "You exceeded your current quota" (Error 429)

**Причина:** Закончились средства на счету OpenAI или превышен лимит

**Решение:**
1. Пополните счет в [OpenAI Billing](https://platform.openai.com/account/billing)
2. Или используйте другой API ключ
3. Подробная инструкция: [FIX_OPENAI_QUOTA.md](FIX_OPENAI_QUOTA.md)

**Важно:** Теперь бот правильно обрабатывает эту ошибку и показывает пользователю понятное сообщение вместо технической ошибки.

### Бот не отвечает на вопросы

**Проверьте:**
1. Логи бота - есть ли ошибки
2. Правильно ли настроен API ключ
3. Работает ли интернет-соединение
