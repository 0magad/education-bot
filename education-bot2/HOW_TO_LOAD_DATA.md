# Как загрузить данные в базу данных

## Пошаговая инструкция

### Шаг 1: Получить User ID пользователя

В базе данных используется **числовой User ID**, а не username (@Rkelmx).

#### Способ 1: Через бота (самый простой)

1. Попросите пользователя написать боту команду `/start`
2. Затем пользователь должен написать команду `/status`
3. В ответе будет показан его **User ID** (это число, например: `123456789`)

#### Способ 2: Через скрипт

1. Убедитесь, что пользователь уже написал `/start` боту
2. Запустите скрипт:
   ```bash
   python get_user_id.py
   ```
3. Скрипт покажет всех пользователей и их User ID

### Шаг 2: Подготовить данные

#### Для таблицы `user_subjects` (ученики и предметы)

Формат: `(user_id, subject_name)`

Пример:
```python
user_subjects_data = [
    (123456789, 'Математика'),  # user_id - это ЧИСЛО из /status
    (123456789, 'Физика'),      # один пользователь может иметь несколько предметов
]
```

#### Для таблицы `schedule` (расписание занятий)

Формат: `(subject_name, lesson_date, lesson_time)`

Пример:
```python
schedule_data = [
    ('Математика', '2024-12-25', '14:00'),  # Математика 25 декабря в 14:00
    ('Математика', '2024-12-27', '14:00'),  # Математика 27 декабря в 14:00
    ('Физика', '2024-12-25', '16:30'),      # Физика 25 декабря в 16:30
]
```

**Важно:**
- `lesson_date` - формат `YYYY-MM-DD` (например: `2024-12-25`)
- `lesson_time` - формат `HH:MM` (например: `14:00`)

### Шаг 3: Загрузить данные

1. Откройте файл `load_data.py`
2. Замените примеры данных на свои (используя User ID из шага 1)
3. Запустите скрипт:
   ```bash
   python load_data.py
   ```

## Как это работает

1. **Таблица `user_subjects`** связывает пользователей с предметами:
   - User ID `123456789` изучает `Математика`

2. **Таблица `schedule`** содержит расписание:
   - `Математика` будет `2024-12-25` в `14:00`

3. **Бот автоматически сопоставляет:**
   - Находит занятие `Математика` на сегодня
   - Находит всех пользователей с предметом `Математика`
   - Отправляет уведомление пользователю с User ID `123456789`

## Проверка

После загрузки данных:

1. Пользователь может проверить свои предметы:
   ```
   /subjects
   ```

2. Пользователь может проверить расписание:
   ```
   /schedule
   /today
   ```

3. Бот автоматически отправит уведомление:
   - Утром (7:00-10:00) о всех занятиях на день
   - За час до занятия

## Важные замечания

1. ❌ **НЕ используйте** username (`@Rkelmx`) - нужен числовой User ID
2. ✅ **Используйте** User ID из команды `/status` или `get_user_id.py`
3. ✅ Пользователь должен сначала написать `/start` боту
4. ✅ Названия предметов должны совпадать в обеих таблицах
5. ✅ Формат даты: `YYYY-MM-DD` (например: `2024-12-25`)
6. ✅ Формат времени: `HH:MM` (например: `14:00`)
