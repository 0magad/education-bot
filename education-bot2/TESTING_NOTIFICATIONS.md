## Как протестировать

### Вариант 1: Тест при запуске

1. Убедитесь, что в `load_data.py` указана сегодняшняя дата и время в будущем:
   ```python
   schedule_data = [
       ('Математика', '2024-12-20', '01:20'),  # Сегодня в 01:20
   ]
   ```

2. Загрузите данные:
   ```bash
   python load_data.py
   ```

3. Запустите бота:
   ```bash
   python bot.py
   ```

4. **Сразу после запуска** вы должны получить уведомление:
   ```
   🤖 Бот запущен!
   
   📚 У тебя сегодня Математика в 01:20.
   Не забудь подготовиться! ✨
   ```

### Вариант 2: Тест для ближайшего времени

Если хотите протестировать прямо сейчас:

1. Узнайте текущее время (например, сейчас 14:30)
2. Установите занятие на время через 1-2 часа (например, 16:00):
   ```python
   schedule_data = [
       ('Математика', '2024-12-20', '16:00'),  # Через 1.5 часа
   ]
   ```

3. Загрузите данные и перезапустите бота

4. Уведомление придет:
   - Сразу при запуске
   - За час до занятия (в 15:00)

## Важные замечания

1. **Формат времени**: Всегда используйте `HH:MM` с ведущим нулем:
   - ✅ Правильно: `'01:20'`, `'14:00'`, `'09:30'`
   - ❌ Неправильно: `'1:20'`, `'9:30'`

2. **Дата**: Используйте формат `YYYY-MM-DD`:
   - ✅ Правильно: `'2024-12-20'`
   - ❌ Неправильно: `'20-12-2024'`, `'2024/12/20'`

3. **Проверка данных**: Убедитесь, что:
   - Пользователь добавлен в `user_subjects` с правильным User ID
   - Предмет в `schedule` совпадает с предметом в `user_subjects`
   - Дата указана правильно (сегодня для теста)

## Отладка

Если уведомления не приходят:

1. Проверьте логи бота - там будет информация о том, что происходит
2. Убедитесь, что пользователь написал `/start` боту
3. Проверьте, что данные загружены правильно:
   ```bash
   python get_user_id.py
   ```
4. Проверьте расписание через команду `/today` в боте
