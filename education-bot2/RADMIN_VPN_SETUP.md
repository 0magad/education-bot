# Настройка подключения через Radmin VPN

Эта инструкция поможет настроить бота на ноутбуке для работы с Ollama на компьютере через Radmin VPN.

## Шаг 1: Проверка подключения Radmin VPN

1. **На компьютере:**
   - Убедитесь, что Radmin VPN запущен и сеть активна
   - Запомните IP адрес компьютера в Radmin VPN сети (обычно начинается с `26.x.x.x`)

2. **На ноутбуке:**
   - Убедитесь, что Radmin VPN запущен и подключен к той же сети
   - Проверьте, что устройства видят друг друга

## Шаг 2: Узнайте IP адрес компьютера в Radmin VPN

### На компьютере (Windows):

1. Откройте PowerShell или CMD
2. Выполните команду:
   ```powershell
   ipconfig
   ```
3. Найдите адаптер **"Radmin VPN"** или **"TAP-Windows Adapter"**
4. Найдите **IPv4 адрес** (например, `26.123.45.67`)

### Альтернативный способ:

1. Откройте Radmin VPN
2. В списке устройств в сети найдите свой компьютер
3. IP адрес будет показан рядом с именем устройства

**Пример:** `26.123.45.67`

## Шаг 3: Настройка Ollama на компьютере

1. **Убедитесь, что Ollama запущен:**
   ```powershell
   ollama serve
   ```

2. **Проверьте, что Ollama слушает на всех интерфейсах:**
   - Если еще не настроено, установите переменную окружения:
     ```powershell
     $env:OLLAMA_HOST="0.0.0.0:11434"
     ```
   - Или создайте системную переменную окружения `OLLAMA_HOST` со значением `0.0.0.0:11434`

3. **Проверьте, что Ollama доступен:**
   ```powershell
   curl http://localhost:11434/api/tags
   ```
   Должен вернуться список моделей.

## Шаг 4: Настройка файрвола на компьютере

Нужно разрешить подключения к порту 11434 через Radmin VPN:

1. Откройте **"Брандмауэр Защитника Windows"**
2. Нажмите **"Дополнительные параметры"**
3. Выберите **"Правила для входящих подключений"** → **"Создать правило"**
4. Выберите:
   - **Тип правила:** Порты
   - **Протокол:** TCP
   - **Порты:** 11434
   - **Действие:** Разрешить подключение
   - **Профиль:** Отметьте все (Домен, Частная, Публичная)
   - **Имя:** Ollama через Radmin VPN

## Шаг 5: Проверка подключения с ноутбука

**На ноутбуке** выполните:

```powershell
# Замените 26.123.45.67 на IP адрес вашего компьютера из Radmin VPN
Test-NetConnection -ComputerName 26.123.45.67 -Port 11434
```

Или:

```powershell
curl http://26.123.45.67:11434/api/tags
```

Если подключение успешно, вы увидите список моделей Ollama.

## Шаг 6: Настройка бота на ноутбуке

1. Откройте файл `.env` на ноутбуке

2. Укажите IP адрес компьютера из Radmin VPN сети:
   ```env
   OLLAMA_BASE_URL=http://26.123.45.67:11434
   OLLAMA_MODEL=llama3.1
   AI_PROVIDER=ollama
   ```

   **Важно:** Замените `26.123.45.67` на реальный IP адрес вашего компьютера из Radmin VPN!

3. Сохраните файл

## Шаг 7: Запуск

1. **На компьютере:**
   - Убедитесь, что Radmin VPN запущен и подключен к сети
   - Убедитесь, что Ollama запущен (`ollama serve`)
   - IP адрес в Radmin VPN должен быть постоянным (или запомните его)

2. **На ноутбуке:**
   - Убедитесь, что Radmin VPN запущен и подключен к той же сети
   - Запустите бота:
     ```bash
     python bot.py
     ```

## Устранение проблем

### Бот не может подключиться к Ollama

1. **Проверьте, что оба устройства подключены к Radmin VPN:**
   - На обоих устройствах должна быть зеленая точка в Radmin VPN
   - Устройства должны видеть друг друга в списке

2. **Проверьте IP адрес:**
   ```powershell
   # На компьютере
   ipconfig
   # Найдите IP адрес адаптера Radmin VPN
   ```

3. **Проверьте файрвол на компьютере:**
   - Убедитесь, что правило для порта 11434 создано и активно
   - Попробуйте временно отключить файрвол для проверки

4. **Проверьте подключение с ноутбука:**
   ```powershell
   # На ноутбуке
   Test-NetConnection -ComputerName IP_КОМПЬЮТЕРА -Port 11434
   ```

5. **Проверьте, что Ollama слушает на всех интерфейсах:**
   ```powershell
   # На компьютере
   netstat -an | findstr 11434
   ```
   Должно быть `0.0.0.0:11434`, а не только `127.0.0.1:11434`

### IP адрес меняется при каждом подключении

Если IP адрес в Radmin VPN меняется:
- Используйте имя компьютера вместо IP (если поддерживается)
- Или обновляйте `.env` файл при каждом подключении
- Или используйте Cloudflare Tunnel для постоянного URL

### Медленное подключение

- Radmin VPN может быть медленнее локальной сети
- Это нормально - трафик идет через интернет
- Убедитесь, что у обоих устройств стабильное интернет-соединение

## Преимущества Radmin VPN

✅ Простая настройка  
✅ Безопасное соединение (шифрование)  
✅ Работает из любого места  
✅ Не требует настройки роутера  
✅ Бесплатно для личного использования  

## Важные замечания

1. **Radmin VPN должен быть запущен на обоих устройствах** пока вы используете бота
2. **IP адрес в Radmin VPN** может меняться при переподключении - проверяйте его при необходимости
3. **Файрвол** должен разрешать подключения к порту 11434 через Radmin VPN адаптер
