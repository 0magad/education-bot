# Быстрая инструкция: Как добавить данные для @Rkelmx

## Что нужно сделать

### 1. Получить User ID

**Способ 1 (самый простой):**
1. Напишите боту команду `/start`
2. Напишите команду `/status`
3. Скопируйте **User ID** (это число, например: `123456789`)

**Способ 2:**
```bash
python get_user_id.py
```

### 2. Отредактировать load_data.py

Откройте файл `load_data.py` и замените данные:

```python
# Замените 123456789 на ваш реальный User ID из /status
user_subjects_data = [
    (123456789, 'Математика'),  # ← Вставьте сюда ваш User ID
]

# Расписание занятий
schedule_data = [
    ('Математика', '2024-12-25', '14:00'),  # Математика 25 декабря в 14:00
    # Добавьте больше занятий если нужно:
    # ('Математика', '2024-12-27', '14:00'),
]
```

### 3. Запустить загрузку

```bash
python load_data.py
```

Готово! Бот автоматически отправит уведомление о занятии.

## Пример для сегодня

Если хотите протестировать прямо сейчас:

1. Получите User ID через `/status`
2. В `load_data.py` укажите сегодняшнюю дату:
   ```python
   schedule_data = [
       ('Математика', '2024-12-20', '14:00'),  # Сегодня в 14:00
   ]
   ```
3. Запустите `python load_data.py`
4. Бот отправит уведомление утром (7-10) или за час до занятия

## Важно!

- ❌ **НЕ используйте** `@Rkelmx` или `"@Rkelmx"` - нужен числовой ID
- ✅ **Используйте** число из команды `/status` (например: `123456789`)
- ✅ Формат даты: `2024-12-25` (YYYY-MM-DD)
- ✅ Формат времени: `14:00` (HH:MM)
