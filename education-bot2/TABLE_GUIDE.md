# Руководство по использованию административной панели

## Описание

Административная панель (`table.py`) - это графический интерфейс для загрузки данных в базу данных бота.

## Новая удобная система с двумя вкладками

Теперь работа стала намного проще! Вам не нужно вводить User ID и ФИО для каждого занятия.

### Две вкладки:

1. **👥 Ученики** - добавьте всех учеников один раз (User ID, ФИО, Класс)
2. **📅 Расписание** - добавьте расписание (Класс, Предмет, День недели, Время)

Система автоматически связывает учеников с расписанием по классу!

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите программу:
```bash
python table.py
```

## Использование

### Вкладка 1: Ученики

В этой вкладке вы добавляете всех учеников **один раз**.

#### Структура таблицы:

| Колонка | Описание | Пример |
|---------|----------|--------|
| **User ID** | ID пользователя Telegram (число) | 6218121239 |
| **ФИО** | Полное имя ученика | Иванов Иван Иванович |
| **Класс** | Класс ученика (1-11) | 8 |

#### Пример заполнения:

```
User ID    | ФИО                  | Класс
6218121239 | Иванов Иван Иванович | 8
9876543210 | Петрова Мария Сергеевна | 8
5555555555 | Сидоров Петр Петрович | 9
```

**Важно:** 
- Каждый ученик добавляется **один раз**
- User ID должен быть уникальным
- Класс должен быть от 1 до 11

### Вкладка 2: Расписание

В этой вкладке вы добавляете расписание. **Не нужно указывать User ID или ФИО!**

#### Структура таблицы:

| Колонка | Описание | Пример |
|---------|----------|--------|
| **Класс** | Класс (1-11) | 8 |
| **Предмет** | Название предмета | Математика |
| **День недели** | День недели (строчными буквами) | вторник |
| **Время** | Время в формате HH:MM | 14:00 |

#### Пример заполнения:

```
Класс | Предмет    | День недели | Время
8     | Математика | вторник     | 14:00
8     | Физика     | четверг     | 15:30
8     | Математика | пятница     | 10:00
9     | Химия      | понедельник | 10:00
```

**Важно:**
- День недели: понедельник, вторник, среда, четверг, пятница, суббота, воскресенье
- Время в формате HH:MM (например: 14:00, 09:30)
- Система автоматически свяжет всех учеников указанного класса с этим расписанием

## Автоматическая связь

✅ **Как это работает:**

1. Вы добавляете учеников в вкладке "Ученики"
   - Например: Иванов Иван, класс 8

2. Вы добавляете расписание в вкладке "Расписание"
   - Например: Класс 8, Математика, вторник, 14:00

3. При загрузке в БД система автоматически связывает:
   - Все ученики 8 класса → получают все занятия для 8 класса
   - Если добавить новое занятие для 8 класса → все ученики 8 класса автоматически получат уведомление

## Кнопки

### Вкладка "Ученики":
- **"Добавить строку"** - добавить новую строку в таблицу учеников
- **"Удалить строку"** - удалить выбранную строку
- **"Очистить"** - очистить всю таблицу учеников

### Вкладка "Расписание":
- **"Добавить строку"** - добавить новую строку в таблицу расписания
- **"Удалить строку"** - удалить выбранную строку
- **"Очистить"** - очистить всю таблицу расписания

### Общие кнопки:
- **"Сохранить"** - сохранить данные в файл (автосохранение работает автоматически)
- **"Загрузить в базу данных"** - загрузить все данные в БД

## Автоматическое сохранение

✅ **Ваши данные сохраняются автоматически!**

- При каждом изменении ячейки
- При закрытии программы
- При следующем открытии все данные будут на месте

Данные сохраняются в:
- `data/table_users.json` - ученики
- `data/table_schedule.json` - расписание

## Загрузка в базу данных

1. Заполните обе вкладки (Ученики и Расписание)
2. Нажмите кнопку **"Загрузить в базу данных"**
3. Система покажет результат:
   - Количество загруженных учеников
   - Количество загруженных занятий
   - Связи по классам

**Важно:**
- При каждой загрузке **старое расписание полностью заменяется новым**
- Если убрали "Математику" из таблицы и загрузили - она исчезнет из БД
- Бот работает строго по данным из таблицы

## Валидация данных

Система автоматически проверяет:

✅ **Ученики:**
- User ID - должно быть числом
- Класс - должно быть от 1 до 11
- ФИО - не должно быть пустым

✅ **Расписание:**
- Класс - должно быть от 1 до 11
- День недели - должен быть одним из: понедельник, вторник, среда, четверг, пятница, суббота, воскресенье
- Время - должно быть в формате HH:MM (00:00 - 23:59)

1. **Добавьте учеников (вкладка "Ученики"):**
   ```
   User ID: 123456789, ФИО: Иванов Иван, Класс: 8
   ```

     - Математика во вторник в 14:00
     - Физика в четверг в 15:30
   - Сидоров Петр (9 класс) получит уведомление:
     - Химия в понедельник в 10:00

## Решение проблем

### Ошибка "Необходимо добавить хотя бы одного ученика"
- Перейдите на вкладку "Ученики" и добавьте хотя бы одного ученика

### Ошибка "Необходимо добавить хотя бы одно занятие в расписание"
- Перейдите на вкладку "Расписание" и добавьте хотя бы одно занятие

### Ошибка валидации
- Проверьте формат данных:
  - Класс должен быть от 1 до 11
  - День недели должен быть строчными буквами (понедельник, вторник, и т.д.)
  - Время должно быть в формате HH:MM

### Данные не сохраняются
- Проверьте права доступа к папке `data/`
- Убедитесь, что папка `data/` существует
