# Решение проблемы: "You exceeded your current quota"

## Проблема

При отправке сообщения боту появляется ошибка:
```
Error code: 429 - You exceeded your current quota
```

Это означает, что у вас закончился лимит использования OpenAI API.

## Причины

1. **Закончились средства на счету OpenAI**
2. **Превышен лимит бесплатного кредита** (если использовали бесплатный кредит)
3. **Не настроен биллинг** (не привязана карта для оплаты)

## Решения

### Вариант 1: Пополнить счет OpenAI (РЕКОМЕНДУЕТСЯ)

1. Перейдите на [OpenAI Platform](https://platform.openai.com/)
2. Войдите в свой аккаунт
3. Перейдите в раздел [Billing](https://platform.openai.com/account/billing)
4. Добавьте способ оплаты (если еще не добавлен)
5. Пополните счет

**Минимальная сумма пополнения:** обычно $5-10

### Вариант 2: Использовать другой API ключ

Если у вас есть другой аккаунт OpenAI с активным балансом:

1. Получите новый API ключ
2. Обновите файл `.env`:
   ```
   AI_API_KEY=новый_api_ключ
   ```
3. Перезапустите бота

### Вариант 3: Временно отключить AI-репетитора

Если не можете пополнить счет прямо сейчас:

1. Удалите или закомментируйте строку в `.env`:
   ```
   # AI_API_KEY=ваш_ключ
   ```
2. Перезапустите бота

Бот будет работать, но AI-репетитор будет недоступен. Пользователи получат понятное сообщение об этом.

## Проверка баланса

1. Перейдите на [OpenAI Usage](https://platform.openai.com/usage)
2. Проверьте текущий баланс и использование

## Что изменилось в коде

Теперь бот правильно обрабатывает ошибку 429 и показывает пользователю понятное сообщение:

```
⚠️ Извини, но сейчас AI-репетитор временно недоступен.

Причина: закончился лимит использования OpenAI API.

Что можно сделать:
• Пополните счет в OpenAI
• Или обратитесь к администратору

Попробуй позже или используй другие функции бота!
```

Вместо технической ошибки пользователь увидит дружелюбное сообщение.

## Альтернативные решения (для будущего)

Если OpenAI API слишком дорого, можно рассмотреть:

1. **Anthropic Claude API** - альтернативный провайдер
2. **Google Gemini API** - бесплатный тарифный план
3. **Локальные модели** (Ollama, LM Studio) - бесплатно, но требует мощный компьютер

Для реализации альтернатив потребуется изменение кода в `modules/ai_tutor.py`.

## Проверка после исправления

После пополнения счета или настройки нового ключа:

1. Перезапустите бота
2. Отправьте тестовое сообщение боту
3. Проверьте логи - не должно быть ошибок 429
