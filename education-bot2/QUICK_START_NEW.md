# Быстрый старт с новой структурой

## Новая логика работы

1. **Таблица schedule**: предмет, класс, день недели, время
2. **Таблица users**: user_id, класс, ФИО
3. **Бот автоматически**:
   - Определяет сегодняшний день недели
   - Находит занятия для классов на этот день
   - Находит всех учеников этих классов
   - Отправляет уведомления

## Быстрая настройка

### 1. Получить User ID

Пользователь пишет боту:
```
/start
/status
```

Копируем User ID (число, например: `6218121239`)

### 2. Загрузить данные

Откройте `load_data.py` и укажите:

```python
# Ученики
users_data = [
    (6218121239, 8, 'Иванов Иван Иванович', 'Rkelmx', 'Иван', 'Иванов'),
]

# Расписание
schedule_data = [
    ('Математика', 8, 'вторник', '14:00'),
    ('Физика', 8, 'вторник', '16:30'),
]
```

### 3. Запустить загрузку

```bash
python load_data.py
```

### 4. Запустить бота

```bash
python bot.py
```

## Пример для тестирования

Если сегодня вторник:

```python
schedule_data = [
    ('Математика', 8, 'вторник', '14:00'),  # Сегодня в 14:00
]
```

Бот отправит уведомление всем ученикам 8 класса.

## Важно!

- Дни недели: `понедельник`, `вторник`, `среда`, `четверг`, `пятница`, `суббота`, `воскресенье`
- Время: формат `HH:MM` (например: `14:00`, `09:30`)
- Класс: число от 1 до 11
- User ID: число из команды `/status`

## Команды бота

- `/start` - регистрация
- `/class <номер>` - указать класс
- `/status` - показать информацию (включая User ID)
- `/schedule` - показать расписание на неделю
- `/today` - показать занятия на сегодня
