# Руководство для администратора

## Как загрузить данные в систему

### Вариант 1: Через Excel/CSV файлы (РЕКОМЕНДУЕТСЯ)

Самый простой способ для администратора - заполнить таблицы в Excel и загрузить через скрипт.

#### Шаг 1: Подготовить файлы

1. Откройте папку `data` в проекте
2. Найдите файлы-шаблоны:
   - `users_template.csv` - для учеников
   - `schedule_template.csv` - для расписания

#### Шаг 2: Заполнить данные

**Файл `users.csv` (ученики):**

| user_id | class_level | full_name | username | first_name | last_name |
|---------|-------------|-----------|----------|------------|-----------|
| 6218121239 | 8 | Иванов Иван Иванович | Rkelmx | Иван | Иванов |
| 987654321 | 8 | Петров Петр Петрович | petrov | Петр | Петров |

**Важно:**
- `user_id` - это число (ID пользователя Telegram)
- Чтобы узнать user_id, попросите ученика написать боту `/start`, затем `/status`
- `class_level` - номер класса (1-11)
- `full_name` - полное ФИО

**Файл `schedule.csv` (расписание):**

| subject | class_level | day_of_week | lesson_time |
|---------|-------------|-------------|-------------|
| Математика | 8 | вторник | 14:00 |
| Физика | 8 | вторник | 16:30 |
| Математика | 8 | среда | 10:00 |

**Важно:**
- `day_of_week` - день недели на русском: понедельник, вторник, среда, четверг, пятница, суббота, воскресенье
- `lesson_time` - время в формате `HH:MM` (например: `14:00`, `09:30`)

#### Шаг 3: Сохранить файлы

1. Скопируйте шаблоны:
   - `data/users_template.csv` → `data/users.csv`
   - `data/schedule_template.csv` → `data/schedule.csv`

2. Заполните `users.csv` и `schedule.csv` своими данными

3. Сохраните файлы (в формате CSV, не Excel!)

#### Шаг 4: Загрузить данные

Запустите скрипт:
```bash
python admin_loader.py
```

Скрипт автоматически:
- Загрузит всех учеников из `data/users.csv`
- Загрузит все расписание из `data/schedule.csv`
- Покажет результат

### Вариант 2: Через Excel (с конвертацией в CSV)

Если удобнее работать в Excel:

1. Откройте шаблоны в Excel
2. Заполните данные
3. Сохраните как CSV (Файл → Сохранить как → CSV UTF-8)
4. Запустите `python admin_loader.py`

### Вариант 3: Через SQLite (для продвинутых)

Если знаете SQL, можете работать напрямую с базой данных. См. `SQLITE_MANUAL.md`

## Примеры заполнения

### Пример 1: Добавить нового ученика

В файл `data/users.csv` добавьте строку:
```csv
123456789,8,Новов Иван Иванович,novov,Иван,Новов
```

Запустите: `python admin_loader.py`

### Пример 2: Добавить новое занятие

В файл `data/schedule.csv` добавьте строку:
```csv
Биология,8,пятница,13:00
```

Запустите: `python admin_loader.py`

### Пример 3: Изменить расписание

1. Откройте `data/schedule.csv`
2. Найдите нужную строку
3. Измените время или день
4. Запустите: `python admin_loader.py`

**Примечание:** Если запись с такими же параметрами уже есть, она не будет дублироваться.

## Получение User ID ученика

Чтобы узнать User ID ученика:

1. Попросите ученика написать боту команду `/start`
2. Затем команду `/status`
3. В ответе будет User ID (число)
4. Используйте это число в `users.csv`

## Проверка загруженных данных

После загрузки можно проверить:

```bash
python get_user_id.py
```

Этот скрипт покажет всех учеников в базе данных.

## Важные замечания

1. ✅ **Формат CSV** - используйте запятые как разделители
2. ✅ **Кодировка UTF-8** - сохраняйте файлы в UTF-8
3. ✅ **Дни недели** - только на русском языке, в нижнем регистре
4. ✅ **Время** - формат `HH:MM` с ведущим нулем (например: `09:30`, не `9:30`)
5. ✅ **User ID** - только числа, не username

## Частые ошибки

**Ошибка:** "Файл не найден"
**Решение:** Убедитесь, что файлы находятся в папке `data/` и называются `users.csv` и `schedule.csv`

**Ошибка:** "Ошибка при загрузке"
**Решение:** 
- Проверьте формат CSV (запятые, не точки с запятой)
- Проверьте, что все обязательные поля заполнены
- Проверьте кодировку файла (должна быть UTF-8)

**Ошибка:** "invalid literal for int()"
**Решение:** Проверьте, что `user_id` и `class_level` - это числа, а не текст

## Автоматизация

Можно создать батник (Windows) для быстрого запуска:

**load_data.bat:**
```batch
@echo off
python admin_loader.py
pause
```

Теперь администратор может просто дважды кликнуть на `load_data.bat` для загрузки данных!
