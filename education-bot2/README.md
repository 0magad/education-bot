# Образовательный Telegram-бот с AI-репетитором

Система заботы с элементами ИИ для учащихся разных классов, объединяющая контекстного AI-репетитора, планировщик и справочник знаний.

## Функции

- 🤖 **AI-репетитор** - отвечает на школьные вопросы, решает задачи и примеры, объясняет учебный материал
  - ⚡ **Бесплатные модели**: Groq, Google Gemini (не требует оплаты!)
  - 🖥️ **Локальная модель**: Ollama (работает на вашем компьютере, можно использовать удаленно!)
  - 💰 **Платные модели**: OpenAI (опционально)
- 📅 **Расписание занятий** - автоматические уведомления о предстоящих занятиях
- 📚 **Планировщик задач** - организация учебного процесса (в разработке)
- 📖 **Справочник знаний** - быстрый доступ к учебным материалам (в разработке)
- ⏰ **Автоматические напоминания** - уведомления о занятиях

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `env.example`:
```bash
# Windows PowerShell:
Copy-Item env.example .env

# Linux/Mac:
cp env.example .env
```

4. Получите токен бота у [@BotFather](https://t.me/BotFather) и добавьте его в `.env`:
   ```
   BOT_TOKEN=ваш_токен_здесь
   ```

5. (Опционально) Для работы AI-репетитора настройте один из вариантов:
   - **Рекомендуется Groq** (бесплатно, быстро): [FREE_AI_SETUP.md](FREE_AI_SETUP.md)
   - Или Google Gemini (бесплатно): [FREE_AI_SETUP.md](FREE_AI_SETUP.md)
   - Или **Ollama** (локальная модель, можно использовать удаленно): [REMOTE_OLLAMA_SETUP.md](REMOTE_OLLAMA_SETUP.md)
   - Или OpenAI (платно): [AI_SETUP.md](AI_SETUP.md)

6. Запустите бота:
```bash
python bot.py
```

## Использование

### Для учеников

После запуска бота:

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start` для начала работы
3. Используйте `/class <номер>` для указания вашего класса
4. Используйте `/schedule` или `/today` для просмотра расписания
5. Просто напишите боту вопрос или задачу - AI-репетитор поможет вам!
6. Бот автоматически отправляет уведомления о занятиях

### Для администраторов

Перед использованием бота необходимо загрузить данные:

1. Заполните таблицу `user_subjects` (ученики и их предметы)
2. Заполните таблицу `schedule` (расписание занятий)
3. Используйте скрипт `load_data.py` или загрузите данные напрямую в БД

Подробнее см. `DATA_LOADING.md`

## Удаленное подключение к Ollama

Если у вас есть мощный компьютер и менее мощный ноутбук, вы можете запустить Ollama на компьютере, а бота на ноутбуке. Это позволяет использовать мощную модель без нагрузки на ноутбук.

**Быстрая настройка:**

1. **На компьютере** (где будет Ollama):
   - Установите Ollama: https://ollama.com/download
   - Настройте для работы по сети: `set OLLAMA_HOST=0.0.0.0:11434` (Windows) или `export OLLAMA_HOST=0.0.0.0:11434` (Linux/Mac)
   - Запустите: `ollama serve`
   - Установите модель: `ollama pull llama3.1`
   - Откройте порт 11434 в файрволе

2. **На ноутбуке** (где будет бот):
   - Узнайте IP-адрес компьютера (например, `192.168.1.100`)
   - В файле `.env` укажите:
     ```
     OLLAMA_BASE_URL=http://192.168.1.100:11434
     AI_PROVIDER=ollama
     ```

**Подключение через интернет (из другого города):**

Для подключения из другого города через интернет используйте один из вариантов:

- ✅ **Cloudflare Tunnel** (рекомендуется - самый простой и безопасный): [CLOUDFLARE_TUNNEL_SETUP.md](CLOUDFLARE_TUNNEL_SETUP.md)
- 🔒 **VPN** (самый безопасный, но требует настройки VPN сервера)
- ⚠️ **Проброс портов** (менее безопасно, требует настройки роутера)

**Подробная инструкция:** [REMOTE_OLLAMA_SETUP.md](REMOTE_OLLAMA_SETUP.md)
