# Руководство по работе с расписанием

## Описание

Бот автоматически проверяет расписание на сегодня и отправляет уведомления пользователям о предстоящих занятиях.

## Как это работает

1. **Готовые таблицы**: В базе данных уже есть:
   - Таблица `user_subjects` - связь учеников с предметами (кто какой предмет изучает)
   - Таблица `schedule` - расписание занятий (предмет, дата, время)

2. **Автоматическое сопоставление**: Бот:
   - Проверяет расписание на сегодня из таблицы `schedule`
   - Для каждого занятия находит всех учеников с этим предметом из таблицы `user_subjects`
   - Отправляет уведомления найденным ученикам

3. **Автоматические уведомления**: Бот проверяет расписание каждые 2 часа и отправляет уведомления:
   - **Утром (7:00-10:00)**: О всех занятиях на день
   - **За час до занятия**: Напоминание о конкретном занятии

## Команды для учеников

### Просмотр информации

#### `/subjects`
Показывает список всех ваших предметов (назначенных администратором).

#### `/schedule`
Показывает все ваше расписание (начиная с сегодняшнего дня).

#### `/today`
Показывает только занятия на сегодня.

## Пример использования

1. **Регистрация:**
   ```
   /start
   /class 10
   ```

2. **Просмотр предметов:**
   ```
   /subjects
   ```

3. **Просмотр расписания:**
   ```
   /schedule
   /today
   ```

## Автоматические уведомления

Бот автоматически отправляет уведомления:

- **Утром (7:00-10:00)**: Сообщение со всеми занятиями на день
  ```
  📚 Напоминание о занятиях на сегодня!
  
  ⏰ 14:00 - Математика
  ⏰ 16:30 - Физика
  
  Не забудь подготовиться! ✨
  ```

- **За час до занятия**: Напоминание о конкретном занятии
  ```
  📚 Напоминание!
  
  Сегодня у тебя Математика в 14:00.
  Не забудь подготовиться! ✨
  ```

## Важные замечания

1. Предметы и расписание добавляются администратором в базу данных
2. Уведомления отправляются автоматически всем ученикам с соответствующим предметом
3. Уведомления отправляются только для занятий, которые еще не были уведомлены
4. Бот проверяет расписание каждые 2 часа

## Для администраторов

Данные загружаются в базу данных через скрипт `load_data.py` или напрямую через SQL.
Подробнее см. файл `DATA_LOADING.md`.

## Устранение проблем

**Проблема**: "У тебя пока нет предметов"
**Решение**: Обратитесь к администратору для добавления предметов

**Проблема**: Не приходят уведомления
**Решение**: 
- Убедитесь, что предмет добавлен в таблицу `user_subjects`
- Проверьте, что занятие добавлено в таблицу `schedule` на сегодня
- Уведомления отправляются утром (7-10) или за час до занятия
