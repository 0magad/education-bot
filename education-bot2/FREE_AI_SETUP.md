# Настройка бесплатных AI-моделей

## 🎉 Полностью бесплатные провайдеры

Бот теперь поддерживает **полностью бесплатные** AI-модели, за которые не нужно платить!

## Доступные бесплатные провайдеры

### 1. Groq (РЕКОМЕНДУЕТСЯ) ⚡

**Преимущества:**
- ✅ **Полностью бесплатный** - не требует кредитную карту
- ⚡ **Очень быстрый** - 500+ токенов в секунду
- 📊 **30 запросов/минуту** (14,400 запросов/день)
- 🎯 **Отличные модели**: Llama 3.3 70B, Mixtral 8x7B, Gemma 2

**Как получить API ключ:**
1. Перейдите на [Groq Console](https://console.groq.com/)
2. Войдите через Google/GitHub (бесплатно)
3. Перейдите в раздел [API Keys](https://console.groq.com/keys)
4. Нажмите "Create API Key"
5. Скопируйте ключ (начинается с `gsk_`)

**Настройка в `.env`:**
```env
AI_PROVIDER=groq
GROQ_API_KEY=gsk_ваш_ключ_здесь
```

### 2. Google Gemini (Альтернатива) 🌟

**Преимущества:**
- ✅ **Полностью бесплатный** тарифный план
- 📈 **1,500 запросов/день** бесплатно
- 🚀 **Быстрая модель** Gemini 1.5 Flash
- 🎨 Поддержка мультимодальности (текст, изображения)

**Как получить API ключ:**
1. Перейдите на [Google AI Studio](https://aistudio.google.com/app/apikey)
2. Войдите через Google аккаунт
3. Нажмите "Create API Key"
4. Скопируйте ключ

**Настройка в `.env`:**
```env
AI_PROVIDER=gemini
GEMINI_API_KEY=ваш_ключ_здесь
```

## Установка зависимостей

```bash
pip install -r requirements.txt
```

Это установит:
- `groq` - для Groq API
- `google-generativeai` - для Google Gemini API

## Быстрая настройка

### Вариант 1: Groq (рекомендуется)

1. Получите ключ на [console.groq.com](https://console.groq.com/keys)
2. Добавьте в `.env`:
   ```env
   AI_PROVIDER=groq
   GROQ_API_KEY=gsk_ваш_ключ
   ```
3. Перезапустите бота

### Вариант 2: Google Gemini

1. Получите ключ на [aistudio.google.com](https://aistudio.google.com/app/apikey)
2. Добавьте в `.env`:
   ```env
   AI_PROVIDER=gemini
   GEMINI_API_KEY=ваш_ключ
   ```
3. Перезапустите бота

## Модели по умолчанию

- **Groq**: `llama-3.3-70b-versatile` (лучшая бесплатная модель)
- **Gemini**: `gemini-1.5-flash` (быстрая и качественная)
- **OpenAI**: `gpt-4o-mini` (платная)

Вы можете изменить модель в `.env`:
```env
AI_MODEL=llama-3.3-70b-versatile  # Для Groq
AI_MODEL=gemini-1.5-pro            # Для Gemini (более мощная)
```

## Решение проблем

### Ошибка: "Groq не установлен"

**Решение:**
```bash
pip install groq
```

### Ошибка: "Groq API ключ не указан"

**Решение:**
1. Проверьте, что ключ добавлен в `.env`
2. Убедитесь, что ключ правильный (начинается с `gsk_`)
3. Перезапустите бота

### Ошибка: "Rate limit exceeded" (Groq)

**Причина:** Превышен лимит 30 запросов/минуту

**Решение:**
- Подождите минуту и попробуйте снова
- Или переключитесь на Gemini (1,500 запросов/день)

### Ошибка: "Quota exceeded" (Gemini)

**Причина:** Превышен лимит 1,500 запросов/день

**Решение:**
- Подождите до следующего дня
- Или переключитесь на Groq

## Переключение между провайдерами

Вы можете легко переключаться между провайдерами, изменив `AI_PROVIDER` в `.env`:

```env
# Для Groq
AI_PROVIDER=groq
GROQ_API_KEY=ваш_ключ

# Для Gemini
AI_PROVIDER=gemini
GEMINI_API_KEY=ваш_ключ

# Для OpenAI (платный)
AI_PROVIDER=openai
AI_API_KEY=ваш_ключ
```
