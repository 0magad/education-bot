## 🎮 Как использовать

### Для первого развертывания организации

1. **Быстрый старт (рекомендуется):**
   ```bash
   chmod +x deploy.sh
   ./deploy.sh
   # или на Windows: .\deploy.ps1
   ```

2. **Или вручную следуя инструкциям в DEPLOYMENT.md**

3. **Отредактировать конфиги:**
   - `.env` — переменные окружения
   - `organization.yaml` — название, описание, контакт
   - `groups.yaml` — список групп (опционально)

4. **Загрузить данные:**
   - Учащихся и расписание через `python admin_loader.py`

5. **Запустить бота:**
   ```bash
   python bot.py
   ```

### Для администратора

**Документация**: [ADVANCED_FEATURES.md](ADVANCED_FEATURES.md)

- Просмотр логов администратора
- Экспорт данных в Excel
- Проверка здоровья бота: `python health_check.py`
- Резервные копии автоматические и ручные
- Аналитика и статистика
