#### 5️⃣ [config.py](config.py) — ОБНОВЛЁН
**Назначение**: Конфигурация с поддержкой YAML (**TASK 3.1-3.4**)

**Что добавлено**:
```python
from config import Config

# Загрузить конфиги организации
org_name = Config.get_organization_name()

# Получить сообщение с подстановкой переменных

# Получить список групп
groups = Config.get_groups_list()
```

**Новые классы**:
- `ConfigLoader` — загрузка YAML с подстановкой переменных из .env
- `Config` — расширенный класс конфигурации с методами для YAML

## 🚀 Как начать

### Для администратора, развертывающего нового бота:

1. **Прочитайте**: [PHASE_3_SUMMARY.md](PHASE_3_SUMMARY.md) (этот файл)
2. **Следуйте**: [DEPLOYMENT.md](DEPLOYMENT.md) пока вы на нем
3. **Используйте примеры**: [DEPLOYMENT_EXAMPLES.md](DEPLOYMENT_EXAMPLES.md)
4. **Запустите скрипт**: `./deploy.sh` или `.\deploy.ps1`

### Для разработчика, обновляющего конфиги:

1. **Отредактируйте**: `organization.yaml` (название, описание)
2. **Отредактируйте**: `messages.yaml` (тексты на вашем языке)
3. **Отредактируйте**: `groups.yaml` (ваши группы)
4. **Используйте**: `Config.get_message()` в коде вместо жестких строк

### Для администратора, использующего бота:

1. **Изучите**: [ADVANCED_FEATURES.md](ADVANCED_FEATURES.md)
2. **Запустите**: `python health_check.py` для проверки здоровья
3. **Просмотрите логи**: `tail -f data/logs/bot.log`
4. **Создавайте резервные копии**: автоматически каждый день
