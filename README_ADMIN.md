# 📋 Руководство для администратора

## Простая инструкция по загрузке данных

### Что нужно сделать

1. **Заполнить таблицы** в Excel или CSV
2. **Запустить скрипт** для загрузки данных
3. **Готово!** Бот автоматически начнет отправлять уведомления

---

## Способ 1: Через Excel (САМЫЙ ПРОСТОЙ) ⭐ РЕКОМЕНДУЕТСЯ

**Почему Excel?** Нет проблем с кодировкой, удобное форматирование!

### Шаг 1: Создать файлы

1. Откройте Excel
2. Создайте файл `data/users.xlsx` с листом **"Ученики"** (или "users")
3. Создайте файл `data/schedule.xlsx` с листом **"Расписание"** (или "schedule")

### Шаг 2: Заполнить таблицу "Ученики"

| user_id | class_level | full_name | username | first_name | last_name |
|---------|-------------|-----------|----------|------------|-----------|
| 6218121239 | 8 | Иванов Иван Иванович | Rkelmx | Иван | Иванов |
| 987654321 | 8 | Петров Петр Петрович | petrov | Петр | Петров |

**Важно:**
- `user_id` - число (ID из Telegram, получить через `/status` в боте)
- `class_level` - номер класса (1-11)
- `full_name` - полное ФИО

### Шаг 3: Заполнить таблицу "Расписание"

| subject | class_level | day_of_week | lesson_time |
|---------|-------------|-------------|-------------|
| Математика | 8 | вторник | 14:00 |
| Физика | 8 | вторник | 16:30 |
| Математика | 8 | среда | 10:00 |

**Важно:**
- `day_of_week` - день недели: понедельник, вторник, среда, четверг, пятница, суббота, воскресенье
- `lesson_time` - время: `14:00`, `09:30` (с ведущим нулем)

### Шаг 4: Загрузить данные

**Вариант A:** Дважды кликните на `load_data.bat`

**Вариант B:** В командной строке:
```bash
python admin_loader.py
```

## Способ 2: Через CSV файлы

**Внимание:** Если видите непонятные символы в CSV, см. файл `КАК_ОТКРЫТЬ_CSV.txt`

### Шаг 1: Правильно открыть шаблоны

**Важно:** Не открывайте CSV двойным кликом! Используйте правильный способ:

1. Откройте Excel
2. Данные → Получить данные → Из файла → Из текста/CSV
3. Выберите `data/users_template.csv`
4. Кодировка: **UTF-8**, Разделитель: **Запятая**
5. Нажмите "Загрузить"

### Шаг 2: Скопировать и заполнить

1. Скопируйте данные из шаблона в новый файл `data/users.csv`
2. Заполните своими данными
3. Сохраните как CSV UTF-8

**Или проще:** Используйте Excel файлы (.xlsx) - нет проблем с кодировкой!

### Шаг 3: Загрузить данные

```bash
python admin_loader.py
```

## Как получить User ID ученика

1. Попросите ученика написать боту `/start`
2. Затем написать `/status`
3. В ответе будет User ID (число)
4. Используйте это число в таблице

## Примеры

### Добавить нового ученика

В `users.xlsx` или `users.csv` добавьте строку:
```
123456789,8,Новов Иван Иванович,novov,Иван,Новов
```

Запустите: `python admin_loader.py` или `load_data.bat`

```

```

Запустите: `python admin_loader.py` или `load_data.bat`

1. Откройте файл расписания
2. Найдите нужную строку
3. Измените время или день
4. Запустите скрипт загрузки

## Что происходит при загрузке

1. ✅ Скрипт читает файлы
2. ✅ Проверяет данные
3. ✅ Загружает в базу данных
4. ✅ Показывает результат

**Дубликаты не создаются** - если запись уже есть, она не будет добавлена повторно.

## Частые вопросы

**Q: Можно ли использовать Excel?**  
A: Да! Просто создайте `.xlsx` файлы вместо `.csv`

**Q: Нужно ли устанавливать что-то дополнительно?**  
A: Для Excel нужно: `pip install pandas openpyxl`

**Q: Что если я ошибся в данных?**  
A: Просто исправьте файл и запустите скрипт снова. Дубликаты не создаются.

**Q: Как удалить данные?**  
A: Удалите строки из файла и запустите скрипт. Или используйте SQLite для удаления напрямую.
