# Настройка удаленного подключения к Ollama

Эта инструкция поможет настроить бота на ноутбуке для работы с Ollama, запущенным на более мощном компьютере.

## Архитектура

- **Компьютер (мощный)**: Запускает Ollama сервер, доступный по сети
- **Ноутбук**: Запускает Telegram бота, который подключается к Ollama на компьютере

## Шаг 1: Настройка Ollama на компьютере

### 1.1. Установка Ollama (если еще не установлен)

Скачайте и установите Ollama с официального сайта: https://ollama.com/download

### 1.2. Настройка Ollama для работы по сети

По умолчанию Ollama слушает только на `localhost:11434`. Нужно настроить его для работы по сети.

#### Windows:

1. Откройте PowerShell или CMD от имени администратора
2. Найдите IP-адрес вашего компьютера:
   ```powershell
   ipconfig
   ```
   Найдите IPv4 адрес (например, `192.168.1.100`)

3. Запустите Ollama с указанием хоста:
   ```powershell
   $env:OLLAMA_HOST="0.0.0.0:11434"
   ollama serve
   ```

   Или создайте системную переменную окружения `OLLAMA_HOST` со значением `0.0.0.0:11434`

#### Linux/Mac:

1. Установите переменную окружения:
   ```bash
   export OLLAMA_HOST=0.0.0.0:11434
   ollama serve
   ```

   Или добавьте в `~/.bashrc` или `~/.zshrc`:
   ```bash
   export OLLAMA_HOST=0.0.0.0:11434
   ```

### 1.3. Установка модели

Установите нужную модель на компьютере:
```bash
ollama pull llama3.1
```

Или другую модель по вашему выбору.

### 1.4. Настройка файрвола

**Windows:**
1. Откройте "Брандмауэр Защитника Windows"
2. Нажмите "Дополнительные параметры"
3. Создайте правило для входящих подключений:
   - Тип: Порты
   - Протокол: TCP
   - Порт: 11434
   - Действие: Разрешить подключение

**Linux (ufw):**
```bash
sudo ufw allow 11434/tcp
```

**Linux (firewalld):**
```bash
sudo firewall-cmd --add-port=11434/tcp --permanent
sudo firewall-cmd --reload
```

## Шаг 2: Настройка бота на ноутбуке

### 2.1. Узнайте IP-адрес компьютера

На компьютере выполните:
- **Windows**: `ipconfig` (найдите IPv4 адрес)
- **Linux/Mac**: `ifconfig` или `ip addr`

Пример: `192.168.1.100`

### 2.2. Обновите файл .env на ноутбуке

Откройте файл `.env` в корне проекта на ноутбуке и измените:

```env
# Настройки Ollama (удаленный сервер)
OLLAMA_BASE_URL=http://192.168.1.100:11434
OLLAMA_MODEL=llama3.1
AI_PROVIDER=ollama
```

**Важно:** Замените `192.168.1.100` на реальный IP-адрес вашего компьютера!

### 2.3. Проверка подключения

Перед запуском бота проверьте подключение с ноутбука:

```bash
# Windows PowerShell
Test-NetConnection -ComputerName 192.168.1.100 -Port 11434

# Linux/Mac
curl http://192.168.1.100:11434/api/tags
```

Если подключение успешно, вы увидите список моделей.

## Шаг 3: Запуск

1. **На компьютере:** Убедитесь, что Ollama запущен и слушает на `0.0.0.0:11434`
2. **На ноутбуке:** Запустите бота как обычно:
   ```bash
   python bot.py
   ```

## Устранение проблем

### Бот не может подключиться к Ollama

1. **Проверьте, что Ollama запущен на компьютере:**
   ```bash
   # На компьютере
   curl http://localhost:11434/api/tags
   ```

2. **Проверьте, что Ollama слушает на всех интерфейсах:**
   ```bash
   # На компьютере
   netstat -an | findstr 11434
   ```
   Должно быть `0.0.0.0:11434`, а не только `127.0.0.1:11434`

3. **Проверьте файрвол:** Убедитесь, что порт 11434 открыт

4. **Проверьте IP-адрес:** Убедитесь, что ноутбук и компьютер в одной сети

5. **Проверьте подключение с ноутбука:**
   ```bash
   curl http://IP_КОМПЬЮТЕРА:11434/api/tags
   ```

### Ollama работает медленно

- Убедитесь, что компьютер достаточно мощный
- Попробуйте использовать более легкую модель (например, `llama3.2:1b`)
- Проверьте загрузку CPU/GPU на компьютере

## Подключение через интернет (из другого города)

⚠️ **Важно:** Подключение через интернет требует дополнительных мер безопасности!

### Вариант 1: VPN (Рекомендуется - самый безопасный)

**Настройка VPN сервера на компьютере:**

1. **Windows:** Используйте встроенный VPN сервер или установите WireGuard/OpenVPN
2. **Linux:** Установите WireGuard (самый простой):
   ```bash
   sudo apt install wireguard
   wg-quick up wg0
   ```
3. Подключите ноутбук к VPN
4. Используйте локальный IP адрес компьютера в VPN сети

**Преимущества:** Полная безопасность, шифрование трафика

### Вариант 2: Туннелирование через Cloudflare Tunnel (Бесплатно, безопасно)

1. Установите Cloudflare Tunnel на компьютере:
   ```bash
   # Windows: скачайте cloudflared.exe с cloudflare.com
   # Linux:
   wget https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
   chmod +x cloudflared-linux-amd64
   sudo mv cloudflared-linux-amd64 /usr/local/bin/cloudflared
   ```

2. Создайте туннель:
   ```bash
   cloudflared tunnel --url http://localhost:11434
   ```
   Это даст вам публичный URL типа `https://xxxxx.trycloudflare.com`

3. На ноутбуке в `.env` укажите полученный URL:
   ```env
   OLLAMA_BASE_URL=https://xxxxx.trycloudflare.com
   ```

**Преимущества:** Бесплатно, автоматическое HTTPS, безопасно

### Вариант 3: Проброс портов на роутере (Менее безопасно)

⚠️ **Не рекомендуется без дополнительной защиты!**

1. На роутере компьютера настройте проброс порта 11434 на IP компьютера
2. Узнайте внешний IP адрес компьютера (например, через whatismyip.com)
3. На ноутбуке в `.env` укажите:
   ```env
   OLLAMA_BASE_URL=http://ВАШ_ВНЕШНИЙ_IP:11434
   ```

**⚠️ Проблемы безопасности:**
- Ollama не имеет аутентификации - любой может подключиться
- Рекомендуется использовать только с дополнительной защитой (VPN, reverse proxy)

### Вариант 4: Reverse Proxy с аутентификацией (Продвинутый)

Используйте nginx или Caddy с базовой аутентификацией перед Ollama.

### Безопасность

⚠️ **Критически важно:** По умолчанию Ollama не имеет аутентификации. Если ваш компьютер доступен из интернета без защиты, это **очень небезопасно**!

**Рекомендации:**
1. ✅ Используйте VPN (самый безопасный вариант)
2. ✅ Используйте Cloudflare Tunnel (бесплатно и безопасно)
3. ⚠️ Если используете проброс портов - обязательно добавьте reverse proxy с аутентификацией
4. ❌ НЕ открывайте Ollama напрямую в интернет без защиты!

## Альтернативные варианты

Если настройка удаленного подключения сложна, можно использовать:

1. **Groq** (бесплатный, облачный) - измените в `.env`:
   ```env
   AI_PROVIDER=groq
   GROQ_API_KEY=ваш_ключ
   ```

2. **Google Gemini** (бесплатный, облачный) - измените в `.env`:
   ```env
   AI_PROVIDER=gemini
   GEMINI_API_KEY=ваш_ключ
   ```
