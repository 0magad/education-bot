# Новая структура базы данных

## Описание

Система переработана для работы с классами и днями недели вместо индивидуальных предметов и дат.

## Структура таблиц

### Таблица 1: `schedule` (Расписание занятий)

| Столбец | Тип | Описание |
|---------|-----|----------|
| `subject` | TEXT | Название предмета |
| `class_level` | INTEGER | Номер класса (1-11) |
| `day_of_week` | TEXT | День недели (понедельник, вторник, среда, четверг, пятница, суббота, воскресенье) |
| `lesson_time` | TIME | Время занятия (формат: HH:MM) |

**Пример:**
```
Математика | 8 | вторник | 14:00
Физика     | 8 | вторник | 16:30
Математика | 8 | среда   | 10:00
```

### Таблица 2: `users` (Ученики)

| Столбец | Тип | Описание |
|---------|-----|----------|
| `user_id` | INTEGER | ID пользователя Telegram (PRIMARY KEY) |
| `class_level` | INTEGER | Номер класса (1-11) |
| `full_name` | TEXT | ФИО ученика |
| `username` | TEXT | Username в Telegram |
| `first_name` | TEXT | Имя |
| `last_name` | TEXT | Фамилия |

**Пример:**
```
6218121239 | 8 | Иванов Иван Иванович | Rkelmx | Иван | Иванов
987654321  | 8 | Петров Петр Петрович | petrov | Петр | Петров
```

## Как работает система

### Шаг 1: SQL запрос - получение расписания

Бот определяет сегодняшний день недели и делает запрос:

```sql
SELECT * FROM schedule 
WHERE class_level = 8 AND day_of_week = 'вторник'
ORDER BY lesson_time
```

**Результат:** Все занятия для 8 класса на вторник

### Шаг 2: SQL запрос - получение учеников

Для каждого класса делается запрос:

```sql
SELECT user_id, class_level, full_name 
FROM users 
WHERE class_level = 8 AND is_active = 1
```

**Результат:** Все ученики 8 класса

### Шаг 3: Отправка уведомлений

Бот отправляет уведомления всем ученикам класса о занятиях на сегодня.

## Пример работы

1. **Сегодня вторник, 14:00**
2. Бот делает запрос: `SELECT * FROM schedule WHERE class_level = 8 AND day_of_week = 'вторник'`
3. Находит: Математика в 14:00, Физика в 16:30
4. Делает запрос: `SELECT * FROM users WHERE class_level = 8`
5. Находит всех учеников 8 класса
6. Отправляет уведомления:
   ```
   📚 Напоминание о занятиях на сегодня!
   
   ⏰ 14:00 - Математика
   ⏰ 16:30 - Физика
   
   Не забудь подготовиться! ✨
   ```

## Преимущества новой структуры

1. ✅ **Проще управление** - одно расписание для всего класса
2. ✅ **Автоматическое определение дня** - не нужно указывать даты
3. ✅ **Масштабируемость** - легко добавить новые классы и дни
4. ✅ **Единообразие** - все ученики класса получают одинаковые уведомления

## Миграция со старой структуры

Если у вас была старая структура:
1. Удалите старую базу данных: `data/bot.db`
2. Запустите бота - создастся новая структура
3. Загрузите данные через `load_data.py` с новой структурой
