# Быстрый старт

## Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

## Шаг 2: Настройка переменных окружения

1. Скопируйте `env.example` в `.env`:
   ```bash
   # Windows PowerShell:
   Copy-Item env.example .env
   
   # Linux/Mac:
   cp env.example .env
   ```

2. Откройте файл `.env` и укажите токен вашего бота:
   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

## Шаг 3: Получение токена бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в файл `.env`

## Шаг 4: Запуск бота

```bash
python bot.py
```

## Проверка работы

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Укажите свой класс: `/class 10`
4. Проверьте статус: `/status`

Бот будет автоматически отправлять сообщения всем активным пользователям каждые 2 часа.

## Остановка бота

Нажмите `Ctrl+C` в терминале для корректной остановки бота.
