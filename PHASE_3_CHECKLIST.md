- ✅ Никакого изменения исходного кода не требуется

- ✅ Может загружать конфиги YAML через ConfigLoader

- ✅ Может получать группы через Config.get_groups_list()
- ✅ Может добавлять новые переменные в конфиги

- ✅ Может переключать AI провайдеров через .env
- ✅ Может создавать резервные копии вручную или автоматически

## 🚀 Развертывание

### Linux / macOS

```bash
git clone <repo>
cd chatbot
chmod +x deploy.sh
./deploy.sh
# Введите название организации и токен
# ✓ Готово через 5-10 минут!
```

### Windows

```powershell
git clone <repo>
cd chatbot
.\deploy.ps1
# Введите название организации и токен
# ✓ Готово через 5-10 минут!
```
